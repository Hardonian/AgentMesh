# AgentMesh Product Roadmap

## Phase 1: Core Foundation (Current v1.0.0 Release)
- Go-native monorepo: `agentmesh-proxy`, `agentmesh-controller`, `agentmesh-worker`, `agentmesh` CLI
- AgentContract, AgentBOM, and Agent Passport specifications
- A2A protocol support and A2A Firewall
- MCP gateway and MCPGuard subsystem
- Deterministic policy engine and cryptographic config signing
- Capability routing, circuit breakers, safe retries, and rate limiting
- HITL approval workflows and immutable parameter hashing
- Progressive delivery (canary traffic splits and automated rollback)
- Google ADK Go integration and Gemini / Vertex model provider adapters
- OpenTelemetry instrumentation and privacy scrubber

## Phase 2: Enterprise Intelligence & Operational Graphs
- Historical regression prediction based on Agent Passport evidence
- Dynamic cost optimization and multi-cloud route failover
- Automated policy generation from observed ADK workflows
- Enhanced BigQuery tool governance and partition pruning rules

## Phase 3: Global Scale & Distributed Mesh
- Multi-region proxy mesh with distributed state synchronization
- Enterprise SSO (SAML / OIDC) and Workload Identity federation
- Hardware security module (HSM) config signing key management
