## What is AgentMesh?

AgentMesh is the open-source control plane and data-plane security proxy for production AI agents communicating over **A2A (Agent-to-Agent)** and **Model Context Protocol (MCP)**.

It provides deterministic identity, semantic policy, capability-aware routing, graph risk analysis, and progressive delivery between autonomous agents and the systems they can reach.

---

## Release Highlights

### 1. High-Performance Go Data-Plane Proxy

- Single static binary with < 15ms routing overhead.
- Native A2A protocol proxy with cryptographic peer handshakes.
- MCP policy gateway supporting stdio and SSE transports.
- Outage resilience: proxies continue routing with in-memory Last Known Good (LKG) signed configuration when the control plane is offline.

### 2. Deterministic Semantic Policy Engine

- Pure Go deterministic policy gates (`ALLOW`, `DENY`, `REQUIRE_APPROVAL`).
- Zero LLM hallucinations in the authorization path.
- Human-in-the-loop (HITL) approval tokens cryptographically bound to `sha256(canonical_json(parameters))` to eliminate parameter tampering and replay attacks.

### 3. Multi-Stage Capability Routing

- Routes agent requests based on declared capabilities, active health, P95 latency against SLOs, and token budgets.
- Automated fallback chains to secondary agents or backup model providers during outages.

### 4. Deep Google Agent Ecosystem Alignment

- Native support for **Google ADK for Go** agent topology inspection and contract export.
- First-class adapters for **Gemini** and **Vertex AI** with dynamic token cost accounting.
- Helm charts and Kubernetes operators certified for **GKE** and **Google Cloud Run**.
- Automated governance over Google-managed MCP tools (BigQuery, Cloud Storage, Google Maps).

### 5. Multi-Tenant Row-Level Security

- Complete physical and logical tenant segregation backed by PostgreSQL 16+ Row-Level Security (RLS).
- Fail-closed listing and mutating methods on empty or mismatched tenant IDs (`ErrEmptyTenant`).

### 6. Zero-Leak Observability

- OpenTelemetry distributed trace context propagation across multi-agent delegation chains.
- Centralized regex secret scrubber automatically redacting Bearer tokens, OpenAI keys, Anthropic keys, AWS secrets, GCP credentials, and passwords.

## Getting Started

```bash
git clone https://github.com/agentmesh/agentmesh.git
cd agentmesh
go build -o bin/agentmesh ./cmd/agentmesh
./bin/agentmesh demo run
```
